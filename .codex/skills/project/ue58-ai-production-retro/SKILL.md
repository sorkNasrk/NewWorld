# AI Production Retrospective

Create a retrospective when the same AI mistake happens twice or when an avoidable asset/code workflow failure causes meaningful rework.

Output:

- Original task.
- Failure symptom.
- Root cause.
- Correct fix.
- Rule that would have prevented it.
- Best destination: AGENTS.md, a project skill, or Docs/Planning/AI_PRODUCTION_RETROSPECTIVES.md.
- Expiration or review condition.

Rules must be concrete: include trigger, bad example, correct behavior, verification, scope, and expiration.
