# Content Checklist

## Static Mesh

Check scale, pivot, orientation, applied transforms, normals, UV0/UV1, material slots, collision, bounds, LOD/Nanite policy, creation_route, naming, and Data Validation.

## Skeletal Mesh And Animation

Check skeleton, root bone, retarget pose, PhysicsAsset, weights, clipping, root motion policy, animation notifies, loop points, foot sliding, montage/blend use, and skeleton compatibility.

## Texture And Material

Check PBR map intent, sRGB, compression, mips, TextureGroup, resolution budget, tiling, baked lighting artifacts, master/instance split, parameter names, shader cost, translucency, Nanite compatibility, and material slot assignment.

## Audio

Check naming, format, sample rate, channels, loudness/peak, loop clicks, variation fatigue, attenuation, concurrency, Sound Class, Submix, and in-game audition notes.

## UI, Font, And Localization

Check WBP naming, hierarchy, focus, Common UI input routing, safe area, longest localized text, Font Asset usage, icon consistency, contrast, and localization key coverage.

## AI Provenance

Every generated or tool-authored asset needs creation_route, route_decision_reason, authoring_tools, prompt or script parameters, date, task id, candidate count or seed, selected reason, source references, license/provenance, staging path, final path, and QA result.
