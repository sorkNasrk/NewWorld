# Art Direction Brief

Use this file to define reusable visual direction for NewWorld. Do not use generated art as production direction until this brief records the style, constraints, and rejection criteria.

## Defaults

- Production assets live under Content/NewWorld after staging and QA.
- Generated or AI-assisted assets start under Content/NewWorld/AIWork.
- Reference packs should include front, side, back, top orthographic views, a 3/4 beauty view, silhouette, material swatches, separable part callouts, and scale reference.
- AI image prompts require approved prompt text before generation; tool calls pass that prompt verbatim.
- Blender MCP modeling should use locked image planes when reference matching matters.

## Reference Image Pack Requirements

- Orthographic front, side, back, and top views without perspective distortion.
- 3/4 beauty view matching likely in-game camera readability.
- Silhouette sheet at small size.
- Material and color swatches labeled by surface.
- Part breakdown for modular pieces, sockets, rig parts, damage states, or animation-relevant features.
- Scale object or dimensions in centimeters.

## AI Image Prompt Fields

- Subject and role in game.
- Shape language and readable silhouette.
- Camera/view requirement.
- Materials and surface wear.
- Color palette and value grouping.
- Lighting only if it helps evaluation; avoid baked lighting for texture or model references.
- Technical constraints: no text, no watermark, no cropped object, no merged limbs/parts, no unusable perspective.
- Output use: concept, styleboard, orthographic reference, texture source, UI art, icon, or marketing reference.
