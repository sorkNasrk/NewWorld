# Audio Brief

Use this file to define reusable audio direction for SFX, VO, BGM, Ambient, UI, and cinematic audio.

## Defaults

- UE audio assets use clear prefixes: SFX_, VO_, BGM_, AMB_, SW_, SC_, MS_.
- Sound Class and Submix routing must be recorded before production mixing.
- AI-generated audio requires an approved prompt, source model/provider, parameters, task id, license/provenance, and in-game audition notes.
