# AI Production Retrospectives

Use this file when an AI-assisted workflow repeats the same mistake twice or creates avoidable rework.

## Rule

A retrospective is required when the same AI mistake happens twice, one mistake causes meaningful rework, or a tool/process assumption proves wrong. Durable rules should be added only when they will change future behavior.
